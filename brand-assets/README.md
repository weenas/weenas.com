# Weenas Brand Assets

Approved direction: blue minimalist W icon + modern Weenas wordmark.

Folders
- logo/png: complete logo
- icon/png: standalone W mark
- favicon: browser/PWA icons and manifest
- app-icon: 1024px app icon master
- social: profile/avatar assets
- brand-guidelines: usage notes

Important
The approved source artwork originated as a raster concept image. These files are production-ready PNG derivatives for web/app prototyping, but they are NOT a true vector master. A genuine SVG/PDF master should be redrawn from the approved geometry before print, signage, or other large-format use.

Repository usage
- Assets are stored under `brand-assets/`; the homepage uses the W icon and full logo, favicon/Apple touch icons, manifest, and social sharing artwork.
- The favicon manifest uses relative icon paths so it works when this folder is served as-is or copied elsewhere.
- Logo filenames indicate width; full logos preserve their original aspect ratio.
- The current artwork includes light backgrounds; these exports are not transparent cutouts.
